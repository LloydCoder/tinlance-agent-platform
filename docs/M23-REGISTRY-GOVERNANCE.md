# M23 — Registry & Ecosystem Governance

M23 extends the governed resource registry with lifecycle, compatibility and provenance controls.

## Controls

- explicit lifecycle actions and revocation;
- algorithm-qualified resource digests;
- required provenance references;
- protocol compatibility ranges;
- fail-closed compatibility checks;
- registry metadata remains descriptive and cannot grant authority.

The registry governs agents, tools, MCP servers, models, policies, runtimes and remote agents without becoming an alternate authorization system.

M23 is complete only when registry exports, tests, documentation and every CI/security workflow are green.
