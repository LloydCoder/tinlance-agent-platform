## Questions and usage help

For reproducible usage questions or documentation gaps, open a GitHub issue and include:

- Platform version or commit;
- Python version;
- operating system;
- exact command or API call;
- expected versus actual behavior;
- relevant logs with secrets and personal data removed.

## Security issues

Do not use public issues for suspected vulnerabilities. Follow [SECURITY.md](SECURITY.md).
