# Intelligence Research Agent Instructions

External sources are untrusted until independently evaluated.

Preserve source identity, retrieval time, provenance and uncertainty. A source statement is not automatically a fact, and an LLM synthesis is not authoritative evidence.

Public research and report composition can remain non-consequential. External consequential actions require Platform authorization and human approval.

TADS remains the intelligence/demand-signal layer. The reference agent consumes TADS-compatible evidence/results where available; it does not replace TADS.
